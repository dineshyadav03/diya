## 3. What is wrong and still to fix (in this order)

1. **Memory: send only the relevant facts.** `diya_memory.Memory.render_for_model` returns **every accepted fact on every message** when they fit in `MAX_PROFILE_CHARS` (2000). `DIYA_RECALL` is on by default but `diya_recall.choose` only trims when the store overflows. That is why the model always "wants" to mention Hog (fact 16 "has a dog named hog", the owner's own sentence from 2026-10-14; the older Rocky fact is retired). Fix: when recall is on, tell the model only the facts that match this message (by embedding, `nomic-embed-text` is running) plus a very small always-on set (name, allergies), keep the "this is partial" note, and **keep `diya_background.py` as a backstop**. This also shortens every prompt. Look at `diya_recall.py` and `docs/RECALL_DESIGN.md` first. Probably 1 module + 1 test file.
2. **"next Tuesday" date bug.** `diya_calendar_talk.asks()` returns `None` for `next <weekday>` on purpose ("not guessed"), and also for plain "what is on tuesday", so the 4B model answered alone and invented "22 Nov 2026" (a Sunday; the real next Tuesday from Tue 27 Oct is **3 Nov**). Fix in code, not in the prompt: resolve the weekday by code (`diya_when`), put the exact date in the answer and the label, and let the model only word it (the project's own rule: code decides, the model words it). Test with the exact message `"what am I doing next Tuesday?` including its leading quote mark.
3. **The same trimming for the 10 always-on tools** (send the weather tool only when weather is asked, and so on) as `_tools_asked_for` did for the 39 proposals. Small gain (about 1,000 tokens), do it only if the owner still finds replies slow after 1 and 2.
4. **Memory pressure on the machine:** the Claude desktop app holds about 8.9 GB committed, because **old Claude conversations left helper programs running (about 3.9 GB: Windows-MCP and plugin servers from 24 to 26 Oct)**. Some of those conversations have remote control ON, so do not kill them: the owner should quit and reopen the Claude app. Also Discord, ChatGPT Classic, Dropbox, the Dolby service (DtsApo4Service).
